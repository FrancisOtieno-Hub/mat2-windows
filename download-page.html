Photos, PDFs and Office files quietly carry hidden details: where a picture was taken, who wrote a document, which device made it. This free tool removes them before you share a file.

How to use it

  1. Right-click the zip, choose Extract All, and open the new folder.
  2. Drag your files onto Clean-files-with-mat2.cmd.
  3. A cleaned copy appears next to each original, named NAME.cleaned.EXT. Your originals are never changed.

To see what a file contains before and after, open PowerShell in the folder and run .\mat2.cmd --show "C:\path\to\file.jpg".

Please check before you share. This is an experimental build. After cleaning, run .\mat2.cmd --show on the cleaned file to confirm the details are gone. Some files, such as PDFs, may look slightly different after cleaning; that is how metadata removal works.

Verify your download

To check that the file wasn’t changed on its way to you, run this in PowerShell and compare the result with the SHA-256 above:

Get-FileHash .\mat2-windows-{{VERSION}}.zip -Algorithm SHA256

Windows may show a SmartScreen warning because the program isn’t code-signed. After checking the SHA-256, click More info, then Run anyway.
